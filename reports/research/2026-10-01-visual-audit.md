## Too much / leave alone

- **Loading repeats progress imagery.** Current source combines a map car, a second looping car in the panel, and a pulsing brand badge: [loading_screen.dart:307](<terra_nt/lib/features/loading/loading_screen.dart:307>), lines 441 and 599. This is a source-only finding. Keep the map journey; simplify the panel’s progress cue. Adding a “preparing your route” scene would increase noise.
- **Result edit rows already have enough icons.** Number, revert, delete, and drag controls consume considerable width; the Nitmiluk title truncates in [t59-removed.png](<reports/screens/2026-09-30-wave4/t59-removed.png>). These controls have purposes. Add no destination icon or thumbnail to this mode.
- **Region selection is at visual capacity.** Three illustrated choices, terrain backdrop, and progress car already carry the screen. [task58-region-cards.png](<reports/screens/2026-09-30-wave3/task58-region-cards.png>) needs no additional symbols or scenes.
- **Welcome and empty Plan AI have enough art.** Empty Plan AI’s [current capture](<reports/screens/2026-09-30-wave3/t57-plan-empty.png>) is complete. Welcome now uses the same `JourneyScene` in [welcome_screen.dart:73](<terra_nt/lib/features/auth/welcome_screen.dart:73>); its updated composition is source-only here.
- **Saved and normal Result rows are fine.** Regional covers, destination pictures, numbers, and chevrons provide sufficient identity. [t62-saved.png](<reports/screens/2026-09-30-wave5/t62-saved.png>) resolves the repeated-cover problem. No extra row artwork.
- **Empty Saved Routes can stay simple.** It already has `bookmark`, explanatory text, and an action: [saved_routes_screen.dart:358](<terra_nt/lib/features/saved/saved_routes_screen.dart:358>). A second large trip scene is unnecessary.
- **Companions, budget, and activity level can remain text-only.** Solo/Couple/Family/Friends are explicit; generic people icons would distinguish them poorly. Budget/Mid-range/Luxury and Low/Medium/High are ordered choices that pictures cannot clarify reliably. Repeated wallets, gems, or activity silhouettes would mainly decorate these rows. See [onboarding_options.dart:26](<terra_nt/lib/data/seed/onboarding_options.dart:26>).
- **Age, trip length, heat, confidence, and off-grid answers need no illustrations.** Their labels and controls explain the decision. The updated [heat screen](<reports/screens/2026-09-30-wave5/t61-heat.png>) is fine.
- **Explore marker styles are complete.** Category icons identify POIs; numbered Result pins identify route order. Keep these distinct roles. Overlapping Explore markers visible in [task54-markers.png](<reports/screens/2026-09-30-wave1/task54-markers.png>) are a density issue, not missing iconography.
- **Offline failure and Profile are fine.** The existing no-signal scene gives the failure screen identity. Task-63’s [Profile capture](<reports/screens/2026-09-30-task63/profile.png>) already pairs Offline maps with a map icon and clear cache wording.
- **Stop schedules need no icon per activity.** Time plus description is a useful reading structure. Keep the destination hero and existing note icon; add only the practical-section cues above.

## Launcher icon and splash

**Launcher:** the route-and-pin concept suits the product. Its glow and tiny dotted path weaken the small-size silhouette. A flatter, heavier version of the same concept would fit better than a generated landscape. The [adaptive icon XML](<terra_nt/android/app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml:2>) declares background and foreground layers only.

**Splash:** both [launch_background.xml](<terra_nt/android/app/src/main/res/drawable/launch_background.xml:3>) variants contain the canvas background with no active centred image. Android 12+ styles set the splash background but no explicit splash icon resource: [styles.xml:4](<terra_nt/android/app/src/main/res/values-v31/styles.xml:4>). Flutter’s initial session wait is also a plain canvas at [app_launch.dart:46](<terra_nt/lib/app/app_launch.dart:46>).

Use the simplified glyph centred on the existing canvas across these launch stages. No title, landscape, glow, or extra animation is needed. Actual launch timing and platform masking were not verified in this read-only review.
