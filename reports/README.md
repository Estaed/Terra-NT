# Reports — research harvested from unattended runs

## What goes here

Output from research agents started and left running: a deep research pass, an "is this
package still maintained" sweep, a spike writeup. `docs/ADVICE.md` is the ancestor of this
folder — the same kind of artefact, written before the folder existed.

The point is not tidiness, it is limits. Idle quota is wasted quota.

## Rules

- One file per question, named after the question, dated.
- Say which model and when, at the top. A finding ages; a finding without a date cannot be
  judged.
- A report is input, never a decision. Bringing it into `docs/PRD.md` or Blueprint is a
  separate, deliberate step — and Blueprint is amended by `create-architecture`, not by hand.
- `research` (the skill) answers live and hands the decision back; it does not write here.
